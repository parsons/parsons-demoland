Exercise The Type Machine

Every square around the edge of this page calls a function that changes the page. Click them all and see what they do, then find each one in the code. The onclick on a square says which function it calls.

Most of the functions take no input. Two of them take a parameter: setBackground(color) and changeText(newText). The square passes in the value, like setBackground('coral').

Your task

The four corner squares are empty. Write the four functions they call, yourIdea1() through yourIdea4(), so each square changes the page in a new way. Then replace the ? on each square with a label.

Try to make at least one that changes the type, one that changes the page, and one that changes the text.

Ideas

  • Type: fontStyle, color, textShadow, lineHeight, textDecoration
  • Shapes: backgroundColor, border, borderRadius, padding
  • Movement: transform with rotate(), scale(), or translate()
  • Text: put your name on the page, or add something to the start or end of the words
  • Appear and disappear: hide the type, or clear away the stickers

Stretch goal

Rewrite all 16 functions so every square does something different, and relabel the squares to match. It’s your machine now.
