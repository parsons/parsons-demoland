HTML Semantic HTML

A semantic element clearly describes its meaning to both the browser and the developer.
Examples of non-semantic elements: `div` and `span` - Tells nothing about its content.
Examples of semantic elements: `img`, `nav`, and `article` - Clearly defines its content.

Use CSS grid and semantic HTML tags to create a page layout. Apply `order: -1 / 0 / 1;` to a child element to move its position in the grid.
