JavaScript A data portrait of your week

An object groups several pieces of data together under one variable. In this activity, you’ll describe your week as one object.

Object syntax

An object starts and ends with curly braces {}. Inside, each property is a key, a colon, and a value, like subject: "What I ate this week"

The page prints your object every time you change the code. If it disappears, open the console. You’re probably missing a comma or a quote.

The starter object has only one property. To add another one, put a comma after the property before it: 

var pokemon = {
  name: "Squirtle",
  level: 12,
  fainted: false,
  moves: ["Tackle", "Water Gun"]
};

The activity

  1. Pick one subject: what you ate this week, your trips around the city, the music you played, or something else.
  2. Write it as one object. Include at least one string, one number and one boolean, plus at least one array.
  3. Swap with a neighbor. What can they tell about your week from your data alone? Is the data readable?

Stretch goal

Put an object inside your object.
