JavaScript Data types

The most basic part of JavaScript is data, and data comes in a few different types. Each variable in this demo holds a different type, and the page shows the value stored in each one.

Primitive data types

Primitive types are simple, basic types of data.

  • Number: basic numeric values, like 3.14 or 12
  • String: text, written inside quotes, like "Hello!"
  • Boolean: either true or false, written without quotes
  • null: represents no value
  • undefined: a variable exists but hasn’t been given a value yet, like var myUndefined;

Higher level data types

Higher level types group smaller bits of data together.

  • Array: an ordered list of values inside square brackets [], separated by commas
  • Object: a collection of values inside curly braces {}. Each value gets a name, called a key. Unlike an array, an object has no order.

On the page, the object’s keys show up in quotes. That’s just how the page prints objects; you don’t need quotes around keys in your code.
