JavaScript Writing JavaScript

HTML gives a page its content, and CSS gives it style. JavaScript is a programming language that lets the page do things.

The script element

CSS goes inside a <style> element, and JavaScript goes inside a <script> element. Put it at the end of the <body>, so the rest of the page loads first.

Each line of JavaScript is an instruction, and the browser runs them in order, from top to bottom. End each one with a semicolon ;

Anything after // is a comment. JavaScript skips it, so you can use comments to leave notes for the people reading your code.

The console

JavaScript doesn’t put anything on the page unless we tell it to. To see what it’s doing, open the console with the Console button in the Editor panel.

console.log() prints whatever you put inside its parentheses to the console. Text goes inside quotes, like "Hello from JavaScript!"

The console also shows errors, with the line number where they happened. When something isn’t working, check the console first.

Variables

var myName = "Jack"; creates a variable, a named container that stores a value. Here, myName holds the text "Jack".

When we write console.log(myName) without quotes, JavaScript prints the value stored inside the variable.

Try it

  • Change "Jack" to your own name.
  • Add another console.log() with a message of your own.
  • Change console.log(myName) to console.log("myName"). What’s the difference?
  • Delete one of the quotation marks around "Jack" and read the error in the console. Then put it back!

In your own projects

You can also keep JavaScript in its own file, like script.js, and link it with <script src="script.js"></script>, just like linking an external stylesheet.
